ClearRoute v1.3 - waypoint corridor exploration. Upload index.html and service-worker.js to GitHub Pages root. This is experimental, not certified driving navigation. Requires HTTPS and location permission. Route generation uses up to 9 Mapbox Directions API requests per manual search, and up to 5 per automatic refresh every 60 sec. Keep track of usage and token restrictions. Coordinates of requested waypoints are not guaranteed to follow residential shortcuts; routing is still performed by Mapbox.
